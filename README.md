# Objetivo
Realizar a atividade prática aplicando os conceitos estudados nas aulas 15, 16, 17 e 18.

O objetivo é consolidar os conhecimentos fundamentais de JavaScript por meio da resolução de problemas práticos que envolvem situações reais de desenvolvimento, abrangendo os principais recursos da linguagem apresentados em sala de aula.

Durante a atividade, serão trabalhados conceitos relacionados a:

ECMAScript e JavaScript;

Variáveis (var, let e const);

Escopo de variáveis;

Tipagem dinâmica;

Operadores aritméticos, relacionais e lógicos;

Truthy e Falsy;

Comparações simples e estritas (==, ===, !=, !==);

Conversão de tipos (Number(), parseInt(), parseFloat());

NaN e validação de números;

Strings e seus principais métodos;

Template Literals;

Funções, parâmetros e retorno;

Estruturas condicionais (if, else, operador ternário e switch);

Laços de repetição (for e while);

Arrays e seus métodos;

Objetos e manipulação de propriedades;

Métodos utilitários para objetos;

Manipulação de datas com Date.

A atividade é composta por 5 exercícios práticos integradores, nos quais o acadêmico deverá desenvolver soluções utilizando JavaScript.

Os exercícios foram elaborados para simular situações próximas às encontradas em aplicações reais e exigirão a aplicação combinada dos conceitos estudados ao longo das aulas.

 

# Entrega
Desenvolver a solução de todos os exercícios propostos.

Testar o funcionamento dos algoritmos utilizando os exemplos de entrada e saída fornecidos.

Enviar na ferramenta de atividades o link do repositório público do GitHub com todo o código desenvolvido.
